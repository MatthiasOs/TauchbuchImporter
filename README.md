Model mittels ollama in cmd bash starten:

```bash
ollama run qwen2.5vl:7b
```

App starten

```bash 
./mvnw spring-boot:run
```

App local starten:

```bash 
SPRING_PROFILES_ACTIVE=local ./mvnw spring-boot:run
```

idToken aus dem "refresh" Request im Browser nehmen als Bearer Token

Browser öffnen:
`http://localhost:9090`
